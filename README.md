# BLAND Store — starter build

## Included
- Mobile-first BLAND storefront
- Hats and tees catalog
- Richardson 112 labeling for hats
- Vintage/Y2K-inspired tee direction
- Product pages
- Cart prototype
- Mobile-friendly Design Studio
- Upload an image design from your phone
- Assign a saved design to any product
- Add/remove products through the starter admin interface

## Run it
Open `index.html` in a browser, or deploy the folder to a static host such as Netlify, Vercel, or GitHub Pages.

## Important
This is the working storefront prototype. Products/designs are stored in the browser with localStorage, so the Design Studio is not yet a shared cloud admin system. The next production step is connecting a database, authentication, payments, and print/embroidery fulfillment.
